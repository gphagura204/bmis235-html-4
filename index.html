Path Finder

One concept, four ways to learn it: how a link finds a file. Every href="" and src="" on your site is a set of directions. Get them wrong and your menu breaks, images don't load, and pages show up unstyled.

The idea in one sentence

A relative path is directions that start from the folder the current page is in. Same path, different starting folder, different file.

  1. tokyo.htmlstay in this folder
  2. img/tokyo.pnggo DOWN into img/, then find the file
  3. ../styles.cssgo UP one folder, then find the file
  4. Tokyo.png ≠ tokyo.pngspelling and capitals must match exactly

The example site used everywhere in this tool

my-site/
├── index.html
├── styles.css
├── img/
│   ├── home.png
│   ├── london.png
│   ├── tokyo.png
│   └── kyoto.png
└── pages/
    ├── london.html
    ├── tokyo.html
    └── japan/
        └── kyoto.html

How do you learn best?

See it happen

Pick which page you're on and type an href or src. Press Follow the link and watch the browser walk the folders, one step at a time, until it finds the file or hits a 404.

Try one:

    All four pages want the same styles.css in the top folder. But they live in different folders, so each needs different directions to reach it. Right now they all say href="styles.css". Fix each one until every page is styled.
