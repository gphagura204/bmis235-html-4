One File, Every Page

Learn how a single file called styles.css controls the look of your whole website. No coding experience needed.

The big idea

  1. 1
    A website is a few pages. Each page is its own file, like index.html (the home page) or tokyo.html.
  2. 2
    The look lives in one separate file: styles.css. Colors, fonts and sizes all go there, not in the pages.
  3. 3
    Each page has one line that says "use styles.css." It goes near the top of the page: 
    <link rel="stylesheet" href="styles.css">

✅ Change styles.css once, and every page with that line changes.

❌ A page without that line (or with a typo in it) looks plain: white background, black text, blue underlined links. That's the browser's default look.

📘 Words to know
Page / .html file
One page of your website, for example tokyo.html.
Stylesheet / .css file
The file that holds your site's look. Ours is called styles.css.
The link line
<link rel="stylesheet" href="styles.css">. It connects a page to the stylesheet.
rel="stylesheet"
Tells the browser "this file is a stylesheet."
href="styles.css"
Tells the browser which file. The name must match the real file exactly.
<head>
The top section of a page that visitors don't see. The link line goes here.
